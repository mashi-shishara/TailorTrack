# TailorTrack

A web-based tailoring order and fitting management system
for a small tailoring shop.

## Planned Features
- Customer details and measurements
- Orders with quantity and unit price
- Automatic order total calculation
- Order progress and delivery dates
- Fitting alteration checklists
- Payment records and printable receipts

## Technologies
- HTML
- CSS
- JavaScript
- PHP
- MySQL
